TITLE
Messy Data Importer

DESCRIPTION (437/600 characters)
Data cleaning and import pipeline: messy CSV or PDF exports (merged headers, mixed date formats, currency symbols, duplicated rows, split columns) are parsed, cleaned and normalized into one consistent spreadsheet, with a summary tab and a log of every fix applied. Runs as a Python script or directly in Google Sheets with Apps Script. Demo uses fictitious supplier files. Stack: Python (pandas, pdfplumber), Google Sheets, Apps Script.

SKILLS
Python (pandas, pdfplumber), Google Sheets, Apps Script, SQL

RESULT
Supplier exports with mixed date, currency and column formats become one consistent table in seconds.
