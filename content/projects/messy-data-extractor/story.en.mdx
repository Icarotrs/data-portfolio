## The scenario

A common situation: every supplier sends their price and stock list in a different shape. A CSV with semicolons and European decimals, a PDF table, an Excel file with headers merged across two rows. Dates come as `03/04/24`, `2024-04-03` and `April 3`. Someone retypes and fixes these files every week before they can be compared.

## How I'd build it

- **Data extraction** for CSV, Excel and text-based PDF tables that handles different delimiters, encodings and multi-row headers, with a mapping file for each new supplier format.
- A cleanup step: one date format, one currency format, trimmed and title-cased names, split and merged columns fixed, duplicates removed.
- Output to Google Sheets: a clean data tab, a **summary tab** (counts, totals, price changes since the last run) and a **log tab** listing every fix.
- Tests for each kind of problem, run against fictitious supplier files that reproduce them.
